# impression-card

**Current approved version: v1.4.1 — Frozen.**

Turn **a real source photograph** into a faithful, detailed romantic storybook illustration with Monet-inspired light, airy oil-led brushwork and natural foreground-to-background depth. Scene content, objects and composition remain sourced from the input image.

**Editing workflow:** supply the actual source image to an image-editing tool. Text-only image recreation does not ensure photo fidelity. One image per source; no collage.

**Poster experiments:** keep separately under a future `poster/` directory. Do not alter the frozen v1.4.1 illustration rules when testing layouts, type or poster aesthetics.
